# Gamified Donor Retention & Smart Cooldown Re-engagement

Initial MERN application setup.

## Getting started

1. Copy `backend/.env.example` to `backend/.env` and set `MONGODB_URI`.
2. Run `npm.cmd run install:all` from the project root.
3. Run `npm.cmd run dev` from the project root.

The frontend runs at `http://localhost:5173` and the API at `http://localhost:5000`.
